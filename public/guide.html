Access Token คืออะไร

กุญแจที่ให้เว็บอ่านโฆษณาจากบัญชี Meta ของคุณ วางในช่อง Access Token แถบซ้าย (ซ่อนไว้เป็น •••• กดไอคอนเพื่อดูได้)

ต้องมี permission ads_read เท่านั้น ไม่ต้องมีสิทธิ์แก้ไขหรือซื้อโฆษณา
วิธีอายุ
Graph API Explorer1–2 ชั่วโมง
System Userใช้ระยะยาว
แลกเป็น Long-Lived60 วัน
Connect Facebookระบบแลกให้อัตโนมัติ
ส่วนที่ 2 · Token วิธีที่ 1

Graph API Explorer

  1. เข้า developers.facebook.com/tools/explorer
  2. เลือก Meta App ที่ต้องการหรือสร้างใหม่
  3. กด Generate Access Token
  4. เพิ่ม Permission: ads_read
  5. กด Generate แล้ว Copy Tokenวางลงช่อง Access Token
Token วิธีนี้หมดอายุเร็ว (1–2 ชม.) เหมาะกับลองใช้ หรือใช้เป็นต้นทางไปแลกเป็น Token 60 วัน
TIP

ถ้าโหลด Ads แล้วขึ้น error เรื่อง token ให้ลองสร้างใหม่ก่อนเป็นอันดับแรก

ส่วนที่ 2 · Token วิธีที่ 2

System User (ระยะยาว)

  1. เข้า Business Settings ใน Meta Business Suite
  2. ไปที่ Users → System Users
  3. สร้าง System User หรือเลือกที่มีอยู่
  4. กด Generate New Token
  5. เลือก App → เพิ่ม ads_readกด Generate Token
  6. Copy มาวาง
เหมาะกับทีมที่ใช้งานประจำ เพราะไม่ต้องสร้าง Token ใหม่ทุกครั้ง

อย่าลืมกำหนดให้ System User เข้าถึง Ad Account ที่ต้องการดูโฆษณา มิฉะนั้นจะโหลด Ads ไม่ได้

ส่วนที่ 2 · Token วิธีที่ 3

แลกเป็น Token อายุ 60 วัน

  1. เอา Short-Lived Token จากวิธีที่ 1 มาก่อน
  2. หา App ID และ App Secretdevelopers.facebook.com → เลือก App → Settings → Basic
  3. เปิด URL แลก Token ในเบราว์เซอร์เติมค่า APP_ID, APP_SECRET, SHORT_TOKEN
  4. Copy ค่า access_token จาก JSON มาวาง
graph.facebook.com/v21.0/oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=SHORT_TOKEN
ต่ออายุได้โดยเรียก URL เดิมซ้ำก่อนหมดอายุ · อย่าแชร์ App Secret ให้ใครเห็น
ส่วนที่ 2 · Token วิธีที่ 4

Connect Facebook

  1. กดปุ่ม Connect Facebook ที่แถบบนระบบพาไปหน้าอนุญาตของ Facebook
  2. กดอนุญาตระบบแลกเป็น Token อายุ 60 วันให้ในครั้งเดียว
  3. กลับมาที่เว็บปุ่มเปลี่ยนเป็น Facebook Ads พร้อมเลือกบัญชีโฆษณา
ไม่ต้องก๊อป Token เอง — แต่ต้องกดเชื่อมใหม่เมื่อครบ 60 วัน

รับ & ตรวจการแก้ไข จากลูกค้า

  1. ลูกค้าเปิดลิงก์ไม่ต้องล็อกอิน แก้แล้วกดบันทึก

ปิดท้าย

โหลดไม่ขึ้น? เช็คตามนี้

  • Token หมดอายุ
    Explorer อยู่ได้ 1–2 ชม. สร้างใหม่หรือแลกเป็น 60 วัน
  • ไม่มีสิทธิ์
    ต้องมี ads_read และเข้าถึง Ad Account นั้นได้
  • Ad ID ผิด
    ใส่ทีละบรรทัด ไม่มีเว้นวรรคเกิน
  • Export ช้า
    ถ้ามี Ads เยอะ รอแถบสถานะให้เสร็จก่อน
  • Target ว่าง
    กดรีเฟรช Target — บางบัญชี Facebook ไม่ส่งค่าประมาณ
  • ลิงก์ลูกค้าไม่อัปเดต
    สร้างลิงก์ใหม่ (ลิงก์เก่าเป็น snapshot)

พร้อมแล้ว — ล็อกอิน → Project → Token → โหลด Ads
